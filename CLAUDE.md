# CLAUDE.md

Guidance for Claude working in this repo (`okitsdrew/Swimply`).

## Who you work with

Drew is new to making games and to programming. Teach as you go: explain what you are doing and why, warn what a change could affect, and prefer plain words. Treat this repo as a "how to make a game with Claude's help" guide. When Drew asks for something that contradicts an earlier decision or would make a mess, **say so before building** and recommend the clean way. Do not just agree.

## Read first

- `DESIGN.md`: what the game is. The contract. Flag contradictions, do not guess.
- `ARCHITECTURE.md`: the layer rules. `npm run check` enforces them.

## How we work

- Claude writes the code, makes placeholder art (code-drawn) and manages GitHub. Drew supplies ideas, tweaks values, edits maps and art in the tools, and playtests on a Steam Deck.
- **One copy of the project:** the clone at `/home/deck/Swimply` on the Deck. Coding threads work there through **Remote Control** (Claude Code running on the Deck, with Drew's own GitHub login), so what Drew plays is exactly what gets committed. Only **one coding thread at a time** works in that folder (a folder has one branch checked out); talk and planning threads don't need it. If two coding threads are ever needed at once, give each its own git worktree, not a second copy.
- (How we drifted, so it doesn't happen again: for a while threads ran in the cloud with their own copy, edited the Deck through folder access and committed from the cloud. It worked but needed every file compared before each commit, and once a stale tool tab overwrote newer art. When the way of working changes, update this file in the same breath.)
- Use **one short-lived branch per phase**, small named commits, and merge to `main` only after Drew has played it and likes it. `main` stays playable.
- Before pushing, run `npm run check`. Run `npm run smoke` when a change could break play (new systems, the scene, enemies, maps, save); skip it for small, low-risk edits such as text, story lines or tuning numbers (Drew's call, 2026-11-04).
- **Tuning habit:** dev menu changes live in the browser until they reach the code. At the end of a tuning session Drew presses **Export tweaks** (one `swimply-tweaks.json` in Downloads, only the changed values), Claude copies the numbers into the config defaults and commits, then Drew presses **Reset all tweaks** and deletes the file.
- Never commit or push without being asked, except the phase branch for the phase Drew said "go" to.
- Bring files over from Heaven (`/home/deck/Heaven`, read-only reference) **one at a time**, reading each. Never copy the whole repo. Vestiges (skills) are made from scratch, not ported from Heaven's skills (Drew's call).
- No new feature starts until the previous one is finished and committed. Ideas go in the parking lot in the plan doc or `DESIGN.md`, not into code.
- Do not build for the "out of scope" list in `DESIGN.md`.
- Before designing the cutscene system, show Drew the approach first.
- Keep code in the style of the surrounding code. Comment sparingly. Do not put a model name or version in commits or code.

## Commands

- `npm install`: install dependencies.
- `npm run dev`: dev server with hot reload (`localhost:5173`).
- `npm run check`: layer check plus type check.
- `npm run build`: check, then build to `dist/` (what CI runs).
- The game is online at https://okitsdrew.github.io/Swimply/. `.github/workflows/pages.yml` builds and publishes `main` on every push (a minute or two later), so whatever is on `main` is what the world can play. Branches are not published.
- `npm run smoke`: the smoke test (`scripts/smoke.mjs`). Starts its own dev server, plays every map in a hidden browser, spawns and kills every enemy kind, stands in every spawner's zone, wins the Mindscape, dies in it, casts Doomsday and Flame Torrent, picks up the Chef's hat and uses the Hats tab, opens both tools, and fails on any error. About a minute and a half. `npm run smoke garden` does one map. Needs Playwright (`npm i -D playwright && npx playwright install chromium` the first time on a new machine).
- `npm run preview`: serve the built `dist/`.
- Asset maker: `localhost:5173/asset-maker.html` while `npm run dev` runs.
- Level editor: `localhost:5173/level-editor.html` while `npm run dev` runs.
